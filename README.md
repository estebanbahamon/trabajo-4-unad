# Sistema Integral de Gestión - Fase 4
## Programación - UNAD

Este proyecto consiste en un sistema orientado a objetos desarrollado en Python para la empresa **Software FJ**. El objetivo principal es demostrar la implementación robusta de principios de POO y el manejo avanzado de excepciones según los requerimientos de la Fase 4.

### Funcionalidades Principales
- **Gestión de Clientes:** Registro con validaciones estrictas de nombres y documentos.
- **Servicios:** Implementación de servicios de Sala, Equipos y Asesorías mediante polimorfismo.
- **Reservas:** Sistema de confirmación, cancelación y pago con manejo de estados.
- **Logs:** Registro automático de eventos y errores en un archivo `logs.txt`.

### Estructura del Proyecto
- `#trabajo 4.py`: Código fuente con clases abstractas, herencia y simulaciones.
- `logs.txt`: Archivo generado automáticamente con el historial de operaciones.
- `README.md`: Documentación del proyecto.
